## Course Description

An introduction to problem-solving through high-level computer programming using Java. The course covers computer and programming fundamentals, algorithms, input/output, variables, data types, expressions, control structures, loops, functions, classes, and object-oriented programming.

Each topic pairs theory with hands-on lab practice. Students develop problem-solving skills by designing algorithms and gradually translating them into Java programs.

No prior programming experience is required.

## Course Approach

The course follows a problem-solving-first approach:

**Problem → Algorithm / Pseudocode → Flowchart → Java Code**

Students first learn to analyze a problem and design a clear solution. They then represent the solution using algorithms, pseudocode, and flowcharts before implementing it in Java.

As the course progresses, students move from basic programming constructs to functions, classes, and object-oriented programming.
